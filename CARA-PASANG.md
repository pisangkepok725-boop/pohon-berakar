# Cara pasang Pohon Berakar (Minecraft Bedrock)

1. Unduh file PohonBerakar_v2.mcaddon dari repo ini.
2. Ketuk file itu, lalu pilih Minecraft. Add-on masuk otomatis.
3. Buka pengaturan dunia, pilih Behavior Packs, lalu aktifkan Pohon Berakar.
4. Jangan nyalakan fitur eksperimen. Tidak diperlukan.
5. Masuk ke dunia dan dekati pohon. Pohon berubah saat kamu berada dalam jarak sekitar 12 blok.

Catatan:
- Pohon yang sudah diubah versi lama tidak diproses lagi. Coba di dunia baru.
- Pohon raksasa 2x2 dilewati.
